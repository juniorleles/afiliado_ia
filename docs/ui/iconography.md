# Iconography

Validation label: AI Affiliate Platform v3.1
Phase: UX Research, execution 03

Ícone é especificação de forma, não arquivo de código. Na implementação futura, usar um conjunto único de traço, 1,5 px, cantos arredondados, sem cor própria. A cor é a do texto ao lado: Text no item, Primary no item atual, Muted text no item desabilitado.

Tamanhos: 20 px na sidebar, 16 px em botão e campo, 8 px é o ponto do badge e não é ícone.

Todo ícone da sidebar tem o nome da área em texto. O ícone não fica sozinho, exceto quando a sidebar está recolhida em tela estreita. Nesse caso o nome aparece no tooltip.

## Áreas

| Área | Forma | Significado |
| --- | --- | --- |
| Dashboard | Quatro quadrados iguais | O trabalho em aberto, visto de uma vez |
| Pesquisa | Lupa | Busca de mercado |
| Products | Caixa com rótulo | O Product observado. O rótulo do menu é Products |
| Oportunidades | Três barras crescentes | Ordem e recomendação |
| Campanhas | Retângulo com uma dobra | A campanha e a presell em rascunho |
| Relatórios | Barras verticais | Desempenho no tempo |
| Configurações | Dois controles deslizantes | Conta e prontidão |

Por que existe: reconhecer a área sem ler só depois de errar o clique.
Quando usar: sidebar e, se preciso, o cartão correspondente no Dashboard.
Valor de negócio: a pessoa troca de tarefa sem reler o menu.

Não desenhar ícone de marca de rede de anúncio, de marketplace ou de produto. Não usar emoji no lugar do ícone. Os exemplos coloridos da pesquisa de UX viram badge com texto, não carinha.

## Ações recorrentes

| Ação | Forma |
| --- | --- |
| Continuar | Seta para a direita, depois do texto |
| Voltar | Seta para a esquerda, antes do texto |
| Fechar | Cruz |
| Abrir detalhes | Chevron para baixo, vira para cima quando aberto |
| Conta | Círculo com silhueta |

A seta não substitui o verbo do botão.

## O que não ganha ícone

Tabela, métrica, formulário, status. O badge já carrega o estado. Um ícone extra de alerta ao lado de "Bloqueado" repete a mensagem.
