# Interaction Map

Validation label: AI Affiliate Platform v3.1
Phase: UX Research, execution 04

| Origem | Controle | Destino |
| --- | --- | --- |
| Qualquer tela | Sidebar ou Menu | A área escolhida |
| Header | Conta | Configurações |
| Header | Plataforma | Dashboard |
| Dashboard | Continuar | Resultado da pesquisa |
| Dashboard | Abrir em Pesquisas | Pesquisa |
| Dashboard | Escolher Product | Product |
| Dashboard | Abrir em Rascunhos | Detalhe da campanha |
| Dashboard | Revisar | Relatórios |
| Pesquisa | Pesquisar | Resultado da pesquisa |
| Pesquisa | Abrir na tabela | Resultado da pesquisa |
| Resultado | Ver Product | Product |
| Resultado | Ver na Landing page | Landing page |
| Product | Ver Landing page | Landing page |
| Product | Ver oportunidade | Oportunidade |
| Product | Criar campanha | Detalhe da campanha |
| Landing page | Seguir para a oportunidade | Oportunidade |
| Landing page | Voltar ao Product | Product |
| Oportunidade | Criar campanha | Detalhe da campanha |
| Campanhas | Abrir | Detalhe da campanha |
| Detalhe | Abas Presell, Ad, Publicação | O mesmo detalhe |
| Detalhe | Concluir revisão | Relatórios |
| Relatórios | Abas Desempenho, Transações, Otimização | O mesmo relatório |
| Relatórios | Revisar ação pendente | Mantém a ação não executada |
| Configurações | Abas Sessão, Prontidão, Fontes, Laboratório | A mesma tela |
| Configurações | Resolver o que falta | Mensagem sobre a conta de anúncios |
| Configurações | Sair | Mensagem de que a sessão real não encerra |
| Qualquer tela | Ver detalhes técnicos | Painel expansível, fechado por padrão |

Breadcrumb de cada tela liga os níveis anteriores dessa mesma trilha.
