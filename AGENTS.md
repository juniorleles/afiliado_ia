# Afiliado IA — regras do agente

- Uma fase por vez. Roadmap canônico: `docs/ROADMAP.md`. O log original de prompts continua em `docs/ROADMAP_FASES.md`.
- Não comece a fase N+1 enquanto a N não foi validada no ambiente real.
- Páginas publicadas (presell): inglês nativo. Painel admin pode ser PT.
- URL do anúncio = a presell neste app. Affiliate hop só no clique do CTA.
- Proibido: cloaking, página alternativa para revisor de ads, redirect
  forçado para o hop, copiar marca/templates da Flow Pages.
- Age gate e cookies só se forem os mesmos para todo visitante.
- Não misturar código com `mercados-autonomos` nem `affiliate-ai-platform`.
- Não criar markdown extra além do pedido na fase. Atualizar o status no
  ROADMAP quando a fase for implementada (não marcar "completa" sem o
  usuário ter rodado de verdade).
